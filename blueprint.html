🤖 Instructions for Next AI Assistant

1. Security: API Keys (Gemini/Firebase) को कभी भी फ्रंटएंड (app.js) में हार्डकोड न करें। उन्हें हमेशा Render के Environment Variables में रखें।

2. DOM Safety: app.js में किसी भी एलिमेंट को एक्सेस करते समय if ($("id")) का इस्तेमाल करें ताकि पेज क्रैश (Black Screen) न हो।

3. UI/UX: डिज़ाइन में हमेशा डार्क ब्लू (#050b14), सियान नियॉन (#00e5ff), और मोनोस्पेस फॉन्ट्स का इस्तेमाल करें। इस सिनेमैटिक लुक को बनाए रखें।

4. Mic Logic: "Hey Jarvis" वाले लॉजिक को बहुत सावधानी से बदलें। इसमें recognition.onend और recognition.stop() का सही बैलेंस है ताकि वह लूप में न फँसे।
