  • 1. DO NOT TOUCH:Keep setPersistence() in app.js. Removing it breaks the login session and causes black screens.
  • 2. SECURITY:Never put Gemini API keys in frontend (app.js). They belong in Render Environment Variables.
  • 3. DOM SAFETY:Always use if ($("elementId")) before manipulating DOM to prevent crashes if an ID is missing.
  • 4. WAKE WORD:The microphone must be stopped explicitly (recognition.stop()) when the wake word is detected to prevent infinite loops.
